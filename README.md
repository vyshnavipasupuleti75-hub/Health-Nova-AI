# Health-Nova-AI

A clean full-stack college project for medical report uploads, visual health analysis, profile management, and a multilingual voice-enabled healthcare assistant.

## Run locally

1. Copy `backend/.env.example` to `backend/.env` and update the values.
2. Run `npm run install:all` from the project root.
3. Run `npm run dev`.
4. Open `http://localhost:5173`.

The chatbot uses safe, educational demo responses. It does not diagnose or replace a clinician.
